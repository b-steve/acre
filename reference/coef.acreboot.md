## Usage

``` r
# S3 method for class 'acreboot'
coef(
  object,
  types = NULL,
  pars = NULL,
  new.covariates = NULL,
  correct_bias = FALSE,
  ...
)
```

## Arguments

- object:

  an object generated by the bootstrap function "boot.acre()".

- types:

  a character vector, the same as "coef.acre()".

- pars:

  a character vector, the same as "coef.acre()".

- new.covariates:

  a data frame, the same as "coef.acre()".

- correct_bias:

  logical. if TRUE, apply a bias correction method to the bootstrap
  results; otherwise, return the original estimation directly. The bias
  correct method is hat(coef) - (mean(boot_results) - hat(coef)).
