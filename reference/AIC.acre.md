# Calculate AIC for acre Models

Calculate AIC for acre Models

## Usage

``` r
# S3 method for class 'acre'
AIC(..., k = 2)
```

## Arguments

- ...:

  One or more acre model objects.

- k:

  Penalty parameter (default is 2 for AIC).

## Value

A named vector of AIC values or NA if conditions are not met.
