# Extract (negative) log-likelihood for a fitted acre object

Extract (negative) log-likelihood for a fitted acre object

## Usage

``` r
# S3 method for class 'acre'
logLik(object, ...)
```

## Arguments

- object:

  a fitted model from "fit.acre()".

- ...:

  For S3 compatibility.

## Value

a numeric value, the negative log-likelihood of the model
